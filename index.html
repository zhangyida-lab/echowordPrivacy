EchoWords · Chrome extension

Privacy Policy

Effective October 13, 2026

EchoWords is a local-first Chrome extension for saving words you select from web pages, visible YouTube captions, and PDF selections.

Data stored on your device

EchoWords stores saved words, nearby article text or visible caption context, source titles and URLs, capture times, YouTube video IDs and timestamps, and optional Traditional or Simplified Chinese translations and your edits. Vocabulary and local review dates, intervals, and counts are stored in IndexedDB in your current Chrome profile.

Collection, translation, and sharing

EchoWords does not send captured content, vocabulary, browsing history, or usage data to a developer server, analytics provider, advertising service, or other third party. It does not require an account or read or monitor your clipboard.

EchoWords’s use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. It uses this information only to provide the vocabulary features described here.

After you choose a target language, EchoWords uses Chrome’s built-in Translator API to translate saved words on your device. Your target-language preference is stored in localStorage in this Chrome profile. EchoWords does not make a translation network request or use a remote AI provider. Chrome may download and manage the required language pack.

Exports happen only when you choose an export action. Chrome saves the JSON file under your control. Export for iPhone contains only words and translations in your selected language; Export JSON contains full backup records. EchoWords does not upload exports to Google Drive or another service. When you choose Import backup, EchoWords reads only the file you select, merges valid records into local IndexedDB, and does not upload the file.

Chrome permissions

  • activeTab and scripting read your explicit selection after you invoke the capture shortcut on an ordinary web page.
  • Access to https://www.youtube.com/* reads only captions currently rendered on screen and preserves video playback state.
  • storage supports local extension preferences; vocabulary records remain in IndexedDB.
  • contextMenus provides a user-triggered PDF selection capture action.
  • offscreen lets a hidden extension document read the saved localStorage language preference and run on-device translation after capture, even when the vocabulary page is closed.

EchoWords does not download complete YouTube transcripts or automatically collect page content.

Retention and deletion

Data remains in your Chrome profile until you delete individual words, clear the extension’s site data, remove the extension, or delete the browser profile. Removing the extension or profile may permanently remove saved data. You can create a full local backup with Export JSON.

Changes to this policy

If EchoWords later adds network sync, accounts, analytics, or other data use, this policy and the extension’s permissions will be updated before that feature is released.

EchoWords · Chrome 扩展程序

隐私政策

生效日期：2026 年 10 月 13 日

EchoWords 是一款以本地存储为主的 Chrome 扩展程序，用于保存你在网页文章、屏幕上可见的 YouTube 字幕和 PDF 中选取的单词。

保存在设备上的数据

EchoWords 保存单词、附近的文章文本或可见字幕上下文、来源标题和网址、采集时间、YouTube 视频 ID 和时间戳，以及可选的繁体或简体中文翻译和你的修改。词汇记录和本地复习日期、间隔、次数存储在当前 Chrome 配置文件的 IndexedDB 中。

数据收集、翻译与共享

EchoWords 不会将采集内容、词汇、浏览历史或使用数据发送给开发者服务器、分析服务商、广告服务商或其他第三方。它不要求注册账户，也不会读取或监控剪贴板。

EchoWords 对从 Google API 获取的信息的使用遵守 Chrome 网上应用店用户数据政策，包括“有限使用”要求。这些信息仅用于提供本政策所述的词汇功能。

选择目标语言后，EchoWords 使用 Chrome 内置的 Translator API 在设备上自动翻译保存的单词。目标语言偏好保存在当前 Chrome 配置文件的 localStorage 中。EchoWords 不会为翻译发起网络请求，也不使用远程 AI 服务；Chrome 可能下载和管理所需的语言包。

只有你主动选择导出时才会生成文件，Chrome 将 JSON 文件保存到由你控制的位置。导出到 iPhone 仅包含单词及所选语言的翻译；导出 JSON 包含完整备份记录。EchoWords 不会将导出文件上传到 Google Drive 或其他服务。选择导入备份时，EchoWords 只读取你选择的文件，将有效记录合并到本地 IndexedDB，不会上传该文件。

Chrome 权限

  • activeTab 和 scripting：你在普通网页上触发采集快捷键后，读取你明确选中的文本。
  • https://www.youtube.com/*：仅读取当前显示在屏幕上的字幕，并保留视频播放状态。
  • storage：保存本地扩展程序偏好；词汇记录仍保存在 IndexedDB。
  • contextMenus：提供由用户触发的 PDF 选词采集操作。
  • offscreen：即使词汇页面已关闭，也允许隐藏的扩展程序文档读取已保存的 localStorage 语言偏好，并在采集后执行设备端翻译。

EchoWords 不下载完整的 YouTube 字幕稿，也不会自动收集整个页面的内容。

保留与删除

数据会保留在 Chrome 配置文件中，直到你删除单个单词、清除扩展程序的网站数据、移除扩展程序或删除浏览器配置文件。移除扩展程序或配置文件可能永久删除已保存的数据。你可以使用导出 JSON 创建完整的本地备份。

政策变更

如果 EchoWords 日后增加网络同步、账户、分析功能或其他数据用途，本政策和扩展程序权限将在相关功能发布前更新。
